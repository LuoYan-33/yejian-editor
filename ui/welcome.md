# 页间使用指南

欢迎来到页间。这里是一张可以直接书写的纸，你可以从一个标题开始，也可以打开一份已有的 Markdown 文档。

## 开始写作

按 **Ctrl + N** 新建空白文档，按 **Ctrl + O** 打开本地文件。写完后，使用 **Ctrl + S** 保存到自己的文件夹。

> 即时编辑时，点击排好的文字就能修改。选中一段文字后右键，可以直接切换粗体、斜体或标题。

## 试试常用格式

- 在行首输入井号和空格，可以写下标题。
- 用一对星号包住文字，可以写出*斜体*；用两对星号可以写出**粗体**。
- [ ] 点击这个复选框，完成你的第一个待办。
- 右键可插入无序、有序或任务列表。写完一项按 **Enter** 继续，在空项按 **Enter** 结束。选中多行再选列表，可一次转换。
- 右键选择「插入图片」，或者按 **Ctrl + V** 粘贴截图。图片保存在文档里，分享时只需发送这一个文件。
- 在正文右键选择「插入表格」。点击单元格直接输入，右键可在当前位置增删行列，按 Tab 跳到下一格。

## 在文档中穿行

点击左侧大纲可以跳到对应标题。按 **Ctrl + F** 查找文字，点击右上角的「源码」可以查看完整的 Markdown 标记。

## 专注于文字

按 **F8** 收起导航和工具栏，再按一次回到工作区。
